# SMS

> Status: Draft · Last updated: 2026-11-01

**Not in Phase 1.**

- Sending SMS (OTP, reminders): login is handled by Catalyst Authentication with Google, Zoho or e-mail, so no SMS OTP is needed. Reminders are planned in-app only.
- Reading the user's SMS to auto-add transactions is a **Phase 2** feature. It needs explicit consent, on-device parsing where possible, and a clear privacy design; it is not built and no permission is requested today.
