# Platform Documentation

Specs for the client & professional web app (`apps/web`).

Files are numbered by topic and organized flat in this folder:

| Range | Contents |
| --- | --- |
| `15`–`25`, `28`–`30` | Product modules (Dashboard, Users Directory, Access Control, Workforce Control, Services Desk, Order Desk, Assignment Engine, QA Desk, Finance & Escrow, Dispute Center, Communication Center, Audit & Logs, Security, System). |
| `26`–`27` | Platform rules and user-facing policies. |
| `31`–`36` | Lifecycles: order, assignment, QA, payment, dispute, professional. |

Platform-specific UI patterns build on the shared design system in
`docs/Frontend/`. API contracts consumed by the platform app live in
`docs/API/`.
