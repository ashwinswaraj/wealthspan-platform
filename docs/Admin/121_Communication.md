# Communication Process

> Status: Planned · Owner: Ashwin Swaraj · Last updated: 2026-11-01

## Intended steps

Draft a broadcast in System, choose audience and severity, send, and log it in the audit trail. Delivery is not built: the form is local only. Prefer in-app notices first; email and push later (`docs/ADR/ADR-005-Notifications.md`).
