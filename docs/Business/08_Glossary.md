# Glossary

> Status: Draft · Owner: Ashwin Swaraj · Last updated: 2026-11-01

| Term | Meaning |
| --- | --- |
| Project | A money space with its own profit and loss (Personal, or one per business / income source) |
| Section | One of five per project: Income, Expense, Debt & Loan/EMI, Savings & Investing, Festivals & functions |
| Sheet | The Excel-style grid for a section (`SHEETS`) |
| Transaction | An `income`, `expense` or `transfer` row |
| Transfer | Own money moved between own accounts; never counts as income or expense |
| Account | Cash, bank, credit card or wallet |
| Payment mode | cash, upi, debit_card, credit_card, bank_transfer, cheque, wallet |
| Event | A festival or function with an optional budget; `open` or `concluded` |
| Concluding an event | Its expenses start counting in Expense on their own dates |
| Loan / EMI | A debt; each EMI is an expense linked by `loan_id` |
| Investment | Savings item (FD, SIP, mutual fund, gold, ...); money in is a transfer |
| Paise | Integer money unit (1 rupee = 100 paise); all amounts are stored in paise |
| Soft delete | Delete that keeps the row recoverable for 30 days |
| Go | The free 30-day trial tier |
| Pro | Paid plan (monthly or annual) |
| UTR | 12-digit UPI reference a user enters after paying |
| Tool | A fixed action the chatbot can call; the server enforces its confirmation level |
| Audit log | Record of every change: actor, tool, before, after |
