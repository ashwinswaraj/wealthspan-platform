# Tools

Internal developer tooling, generators, and one-off/automation scripts
(data migration, seeding, codegen). Add scripts here as repeat tasks come
up — don't pre-build.

- `cli/`, `codegen/`, `generators/`, `templates/` — developer tooling and code generators
- `database/` — one-off database scripts (migration helpers, seeding)
- `maintenance/` — repo/data maintenance scripts
- `release/` — release automation scripts
- `setup/` — local environment setup scripts
- `testing/` — test data / fixture generation scripts
