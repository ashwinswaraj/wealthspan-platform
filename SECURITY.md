# Security Policy

## Supported Versions

Only the latest release of Jobrio receives security updates.

## Reporting a Vulnerability

Report suspected vulnerabilities privately to **security@jobrio.com**.
Please include reproduction steps, affected area (platform / admin / api),
and any logs. Do not open a public GitHub issue for security reports.

We aim to acknowledge reports within 2 business days and to ship a fix or
mitigation within 30 days depending on severity.

## Scope

- `apps/web`, `apps/admin`, `apps/api`
- `infrastructure/database` policies and functions
- Authentication, authorization and payment flows

See `docs/Security/` for the platform's internal security documentation.
